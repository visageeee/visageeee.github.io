# visage / independent software

Portfolio for Viditron, Sprintathon, Forge Ahead, and Apistat.

Live site: https://visageeee.github.io/

The site is a self-contained `index.html`, with embedded CSS, JavaScript and optimised images. No build system, external fonts, analytics, or dependencies. Edit this file and push to `main` to update GitHub Pages.

Viditron screenshot comes from `visageeee/viditron` (the screenshot shows an earlier working title). Sprintathon image is a still from `visageeee/alephone-sprintathon/mthon.webp`. Forge Ahead and Apistat use decorative illustrations, not screenshots.

Sprintathon is based on Aleph One. Forge Ahead is based on Weland by Gregory Smith. See the respective project repositories for their licences and full credits.
