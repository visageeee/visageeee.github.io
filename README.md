# visage / apps by Olof

A minimal portfolio for Viditron, Sprintathon, Forge Ahead, and Apistat.

Live site: https://visageeee.github.io/

The site is a self-contained `index.html` with embedded CSS. It lists one app per row with short descriptions and project links. No build system, JavaScript, external fonts, analytics, or dependencies. Edit this file and push to `main` to update GitHub Pages.

Sprintathon is based on Aleph One. Forge Ahead is based on Weland by Gregory Smith. See the respective project repositories for their licences and full credits.
